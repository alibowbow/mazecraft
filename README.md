# MazeCraft · 메이즈크래프트

> 길을 설계하고, 물을 흘려보내는 미로와 물의 아틀리에

MazeCraft는 회원가입이나 서버 없이 브라우저에서 동작하는 로컬 퍼스트 웹앱입니다. 홈에서 세 작업 공간으로 들어갑니다.

- **미로 제작**: 도형·글자·이미지·직접 그리기로 미로를 만들고 플레이·공유·인쇄합니다.
- **물의 정원**: 미로와 도자기 정원 위로 물을 흘려보내고 물색·재질·빛을 튜닝합니다.
- **물길 크래프트**: 장치를 이어 물길을 짓고, 실제 물 시뮬레이션이 판정하는 4장 20단계 챌린지에 도전합니다.

홈에는 매일 바뀌는 **오늘의 미로**가 있습니다.

## 주요 기능

- 챌린지: 4장 20단계. 단계마다 새 장치나 요령을 하나씩 가르치는 브리핑과 팁, 힌트 2개, 정답 보기(별 1개로 제한), 목표·시간·장치 수로 매기는 별 3개, 장과 전체를 마칠 때의 완주 화면, 효과음
- 오늘의 미로: 날짜로 정해지는 하루 한 미로(같은 날에는 누구나 같은 미로, 월요일이 가장 쉽고 일요일이 가장 어려움), 연속 기록, 결과 공유
- 물의 정원: 포슬린 가든·캐스케이드·트윈 플로우·리본·워터 가든 프리셋, 2D/3D 보기, 자유 회전·확대
- 5가지 미로 재질, 3가지 조명, 물색·유입량·농도·수면 움직임 튜닝과 설정 복원
- 물레방아·시시오도시·사이펀·아르키메데스 스크류 같은 장치와 Rapier 강체로 물에 뜨는 장난감
- 물길 크래프트: 11개 프리셋, 막힌 물길의 이유와 바로 적용되는 추천 수정, 프리셋·비우기 되돌리기
- 17가지 로컬 벡터 도형, 여러 줄 텍스트, 이미지 전처리, 직접 그리기
- 재현 가능한 seed 기반 DFS·Kruskal·Prim 생성과 Web Worker 후보 비교, 생성 리플레이
- 위쪽 입구·아래쪽 출구 자동 최적화, Maze IQ 지표, 연결성·벽 대칭 검증과 자동 복구
- 벽 열기·닫기, 시작/종료점·아이템·체크포인트 편집, 100단계 실행 취소/다시 실행
- IndexedDB 자동 저장, 새로고침 복구, `.mazecraft` 가져오기, 전체 백업과 복원
- 시크릿 메시지·이미지·링크·쿠폰·장소 힌트와 단계별 공개
- 키보드·드래그·스와이프·D-pad 플레이, 타임어택, 힌트, 개인 기록, 제작자 고스트
- 압축 공유 링크, QR, Web Share, 새 창 플레이, 원클릭 리믹스
- PNG·SVG·A4 문제지/정답지·프로젝트 파일·결과 카드·독립 실행 HTML 출력
- 도움말·설정(테마, 그래픽 품질)·저장 상태·개인정보·오픈소스 고지를 담은 정보 창
- 라이트/다크 모드, 키보드 접근성, 모바일 핀치/이동, 시스템 ‘동작 줄이기’ 설정 존중

## 실행

Node.js 20 이상을 권장합니다(CI는 22).

```bash
npm ci
npm run dev
```

개발 서버가 안내하는 로컬 주소를 브라우저에서 여세요. 휴대폰에서 확인하려면 `npm run dev -- --host`로 실행하고 같은 네트워크에서 안내된 주소로 접속합니다.

## 화면 주소

라우팅은 URL hash를 사용합니다. 브라우저의 뒤로·앞으로 버튼과 새로고침이 같은 화면으로 돌아가고, 아래 주소로 바로 들어갈 수 있습니다.

| 주소 | 화면 |
| --- | --- |
| `/` | 홈 |
| `/#/library` | 홈의 ‘내 미로’ |
| `/#/studio` | 마지막으로 연 미로의 제작실 |
| `/#/water` | 물의 정원 |
| `/#/craft` · `/#/challenges` | 물길 크래프트 자유 제작(처음에는 ‘계단 정원’) · 챌린지 |
| `/#/daily` | 오늘의 미로 |
| `/#/play?data=…` · `/#/water?data=…` | 공유 링크 |

## 빌드와 배포

```bash
npm run build
npm run preview
```

프로덕션 파일은 `dist/`에 생성됩니다. hash 라우팅이라 정적 호스팅에 별도 rewrite 규칙이 필요하지 않습니다.

Vercel 배포 설정은 `vercel.json`에 있습니다. 모든 응답에 `nosniff`, `Referrer-Policy`, `Permissions-Policy`를 붙이고, 파일명에 해시가 들어간 `/assets/*`는 1년 동안 변경 없이 캐시합니다. 그래서 `/assets/` 아래에는 Vite가 만든 파일만 두고, 화면에서 쓰는 이미지는 `src/assets/`에서 import합니다.

| 환경 변수 | 용도 |
| --- | --- |
| `SITE_URL` | 링크 미리보기(Open Graph)의 절대 주소. 기본값 `https://mazecraft.vercel.app` |

배포 중에 새 버전이 올라가면 열려 있던 탭이 사라진 화면 파일을 요청할 수 있습니다. 앱은 이때 한 번 자동으로 새로고침하고, 1분 안에 다시 실패하면 새로고침 안내 화면을 보여 줍니다. 화면 하나에서 오류가 나도 앱 전체가 비지 않고 복구 화면과 ‘홈으로’를 제공합니다.

의존성을 바꾼 뒤에는 `npm run licenses`로 `public/licenses.txt`(번들에 포함된 패키지의 라이선스 전문)를 다시 만드세요.

E2E는 제작, 재생성, 플레이·완주, 시크릿 공개, 자동 저장 복구, 파일 가져오기/내보내기, 공유 링크, 리믹스, 편집 이력, PNG·SVG 출력, 3D 물 흐름, 크래프트와 챌린지, 모바일 레이아웃과 외부 요청 부재를 확인합니다. 설치된 Chromium을 쓰려면 `PLAYWRIGHT_EXECUTABLE_PATH`에 실행 파일 경로를 지정합니다.

## 프로젝트 데이터 구조

프로젝트의 원본은 Canvas 픽셀이 아니라 셀과 벽으로 이루어진 그래프입니다.

| 영역 | 주요 데이터 |
| --- | --- |
| 식별·버전 | `schemaVersion`, `appVersion`, `id`, `createdAt`, `updatedAt` |
| 제작 설정 | `seed`, `canvas`, `grid`, `shape`, `mask` |
| 미로 | `mazeGraph`, `startCell`, `endCell`, `difficulty`, `mazeMetrics` |
| 게임 | `gameRules`, `collectibles`, `checkpoints`, `creatorReplay` |
| 표현 | `visualTheme`, `background`, `secretReveal` |
| 공유·출력 | `remixAllowed`, `creatorDisplayName`, `exportSettings`, `attribution` |

`mazeGraph.cells`는 행 우선 순서로 저장되며 각 셀은 활성 여부와 상·우·하·좌 벽 상태를 가집니다. 가져오기 시 스키마 버전을 검사하고, 지원 가능한 이전 형식은 현재 스키마로 마이그레이션합니다.

## 저장 방식

- IndexedDB: 프로젝트 본문과 선택적 Blob 자산
- localStorage: 테마·그래픽 품질 설정, 마지막 프로젝트, 개인 기록, 크래프트 물길, 챌린지 별·단계별 최고 기록(`mazecraft.challenges.v1`), 오늘의 미로 기록(`mazecraft.daily.v1`, 최근 400일), 물의 정원 튜닝, 소리·카메라 선택
- 자동 저장: 변경을 모아 debounce한 뒤 저장하고 `pagehide`에서 마지막 초안을 기록
- 저장소 추상화: `ProjectRepository`와 `ProjectAssetRepository` 인터페이스 뒤에 로컬 구현을 배치
- 브라우저가 IndexedDB를 막으면 메모리 저장소로 전환하고, 홈에 ‘탭을 닫으면 사라진다’는 경고를 표시
- 저장 공간 부족 같은 저장 실패는 원인과 대처를 알려 주는 안내로 표시

‘도움말과 설정 → 저장과 개인정보’에서 저장 사용량을 보고, 브라우저에 삭제 방지를 요청하고, **전체 백업**을 받을 수 있습니다. 백업 JSON 하나에 모든 프로젝트와 위 localStorage 기록이 들어갑니다. 복원은 같은 메뉴나 홈의 ‘파일 열기’로 합니다. 같은 프로젝트는 백업 쪽이 더 최신일 때만 바뀌고, 챌린지 별은 낮아지지 않으며, 최고 기록과 오늘의 미로 기록은 두 쪽을 합쳐 더 빠른 기록을 남깁니다. 이 기기에서 이미 고른 설정은 유지합니다.

향후 서버 저장을 추가할 때는 저장소 인터페이스 구현을 교체하고, 제작·플레이 UI와 미로 엔진은 그대로 유지할 수 있습니다.

## 공유 링크

공유 데이터는 셀당 5비트 그래프 패킹 후 DEFLATE로 압축하고 URL-safe Base64로 변환해 다음 hash에 넣습니다.

```text
/#/play?data=압축된데이터
```

공유 링크로 열면 홈이나 편집기를 거치지 않고 플레이 화면으로 진입합니다. 이미 열린 탭의 주소창에 붙여 넣어도 바로 열립니다. 해답, 제작자 고스트, 제작자 표시명과 리믹스 허용 여부는 공유 전에 선택할 수 있습니다.

안전 한도는 전체 URL 2,000자입니다. 이를 넘으면 링크와 QR 생성을 중단하고 `.mazecraft` 파일 또는 독립 실행 HTML 사용을 안내합니다. 큰 이미지나 긴 고스트는 링크 한도를 빠르게 소모합니다.

## 독립 실행 HTML

공유 단계의 파일 내보내기에서 `독립 실행 HTML`을 선택하면 미로 그래프, 플레이어, 스타일, 시크릿 콘텐츠와 선택한 고스트가 한 파일에 포함됩니다. 다운로드한 파일은 인터넷 연결 없이 열어 키보드, 스와이프와 D-pad로 플레이할 수 있습니다. 이 파일은 플레이 전용이며 편집 프로젝트로 다시 가져오지 않습니다.

## 지원 브라우저

- 최신 두 버전의 Chrome, Edge, Firefox
- Safari 16.4 이상
- IndexedDB, Web Worker, Canvas 2D, WebGL 2, Blob URL을 지원하는 최신 모바일 브라우저

`navigator.share`가 없는 데스크톱 브라우저에서는 링크 복사와 QR을 사용합니다. 물의 정원과 크래프트는 처음 열 때만 Three.js 모듈을 지연 로드합니다. 그래픽 품질 ‘자동’은 컴퓨터에서 선명하게, 메모리나 코어가 적은 휴대폰·태블릿에서 가볍게 그리며, 정원의 후처리는 프레임이 계속 느리면 한 단계씩 낮아집니다. 운영체제의 파일 URL 정책이 엄격한 환경에서는 독립 HTML을 로컬 정적 서버로 열어야 할 수 있습니다.

## 물 시뮬레이션

물을 움직이는 모델은 세 가지입니다. 2D 보기는 Web Worker의 자유수면 입자 시뮬레이션, 3D 미로 수조는 셀을 저장 control volume으로 보고 열린 통로를 유량 edge로 적분하는 질량 보존 네트워크입니다. 물의 정원 프리셋과 크래프트는 수조마다 수심 평균 천수 격자를 두고 둑·장치로 잇는 질량 보존 모델(`garden/physics`)을 쓰며, 물에 띄우는 장난감은 Rapier 강체입니다. 게임용 상호작용 시뮬레이션이며 공학용 유체 해석기는 아닙니다.

자세한 설계는 [자유수면 물 시뮬레이션](docs/free-surface-water.md)과 [Water Dynamics 2.0 설계 문서](docs/water-dynamics-2.md)에 있습니다.

## 실제 제한사항

- 공유 링크는 전체 2,000자까지만 생성합니다.
- 브라우저가 IndexedDB를 차단하면 메모리 저장소로 전환되며 해당 탭을 닫으면 유지되지 않습니다(홈에 경고 표시).
- PNG는 브라우저 메모리 보호를 위해 한 변 16,384px, 전체 64MP 이하로 제한합니다.
- 독립 실행 HTML은 부분 셀 마스크 공개 대신 완주 시 전체 시크릿 공개를 사용합니다.
- WebGL 2를 쓸 수 없으면 물의 정원과 크래프트는 하드웨어 가속을 켜거나 최신 브라우저를 쓰라는 안내를 표시합니다. 미로 제작과 플레이는 Canvas 2D로 계속 동작합니다. 그래픽 장치가 리셋되면 장면을 일시정지하고, 브라우저가 복구하거나 ‘다시 시작’을 누르면 새로 준비합니다.
- 서비스 워커가 없어 오프라인에서는 열리지 않습니다. 홈 화면에 설치(manifest)는 가능합니다.
- 서버 순위표, 계정 동기화, 실시간 멀티플레이와 대용량 미디어 호스팅은 포함하지 않습니다.
